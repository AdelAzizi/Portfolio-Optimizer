# قوانین ارتباط و گفت‌وگو

## زبان گفت‌وگو
- **چت و مکالمه:** همیشه به زبان فارسی
- **کد و کامنت‌ها:** به زبان انگلیسی
- **لاگ‌ها و خروجی ترمینال:** به زبان انگلیسی
- **نام متغیرها و توابع:** به زبان انگلیسی
- **مستندات فنی:**  به زبان انگلیسی و فارسی

## سبک پاسخ‌دهی
- پاسخ‌ها باید مختصر و مفید باشند
- توضیحات فنی را ساده و قابل فهم ارائه کن
- همیشه مثال عملی ارائه بده
- در صورت بروز خطا، راه‌حل واضح پیشنهاد کن

## اولویت‌های پروژه
- کیفیت کد بالاتر از سرعت توسعه
- مستندسازی همزمان با کدنویسی
- تست کردن هر بخش قبل از ادامه
- استفاده از best practices در Python

## قوانین کدنویسی
- استفاده از type hints
- docstrings کامل برای توابع
- error handling مناسب
- logging به زبان انگلیسی
- نام‌گذاری واضح و معنادار
