# 📈 راهنمای تحلیلگر رژیم بازار

## 🎯 هدف و کاربرد

این ابزار برای **تشخیص و تحلیل رژیم‌های مختلف بازار و عملکرد استراتژی‌ها در هر رژیم** طراحی شده است. بازار سهام مانند آب و هوا دارای فصل‌های مختلف است - گاهی صعودی، گاهی نزولی، و گاهی خنثی. این ابزار به شما کمک می‌کند:

- **رژیم فعلی بازار را تشخیص دهید**
- **بفهمید کدام استراتژی در کدام رژیم بهتر عمل می‌کند**
- **استراتژی‌های مقاوم در برابر تغییر رژیم را شناسایی کنید**

## 🔧 چگونه کار می‌کند؟

### مرحله 1: تشخیص رژیم بازار
```python
# استفاده از الگوریتم Hidden Markov Model (HMM)
رژیم‌های شناسایی شده:
- 🟢 رژیم صعودی (Bull Market): قیمت‌ها رو به بالا
- 🔴 رژیم نزولی (Bear Market): قیمت‌ها رو به پایین  
- 🟡 رژیم خنثی (Sideways): قیمت‌ها نوسانی
```

### مرحله 2: تحلیل عملکرد در هر رژیم
```python
# برای هر استراتژی در هر رژیم محاسبه می‌شود:
- Sharpe Ratio
- بازدهی میانگین
- نوسان (Volatility)
- حداکثر افت (Max Drawdown)
```

### مرحله 3: شناسایی استراتژی‌های متخصص و مقاوم
```python
# دو نوع استراتژی شناسایی می‌شود:
- متخصص: در یک رژیم خاص عالی عمل می‌کند
- مقاوم: در تمام رژیم‌ها عملکرد مناسب دارد
```

## 📊 معیارهای کلیدی

### 🎯 Regime Detection Accuracy (دقت تشخیص رژیم)
- **محدوده**: 0 تا 1 (1 = تشخیص کامل)
- **معنی**: دقت الگوریتم در تشخیص رژیم‌ها
- **مطلوب**: بالای 0.8

### 📈 Regime-Specific Performance
برای هر رژیم:
- **Bull Market Performance**: عملکرد در بازار صعودی
- **Bear Market Performance**: عملکرد در بازار نزولی
- **Sideways Performance**: عملکرد در بازار خنثی

### 🛡️ Regime Resistance Score (امتیاز مقاومت)
- **محدوده**: 0 تا 1
- **معنی**: میزان مقاومت استراتژی در برابر تغییر رژیم
- **محاسبه**: بر اساس پایداری عملکرد در رژیم‌های مختلف

### ⚡ Regime Transition Impact (تأثیر تغییر رژیم)
- **معنی**: چقدر تغییر رژیم بر عملکرد استراتژی تأثیر می‌گذارد
- **مهم**: کمتر بهتر است

## 📈 نحوه تفسیر نتایج

### نمونه خروجی:
```json
{
  "regime_analysis": {
    "current_regime": "bull_market",
    "regime_probabilities": {
      "bull_market": 0.75,
      "bear_market": 0.15,
      "sideways": 0.10
    },
    "strategy_performance": {
      "strategy_1": {
        "bull_market": {"sharpe": 1.8, "return": 0.25},
        "bear_market": {"sharpe": 0.3, "return": -0.05},
        "sideways": {"sharpe": 1.2, "return": 0.12},
        "resistance_score": 0.65
      }
    }
  }
}
```

### تفسیر این نتایج:

#### 🟢 **رژیم فعلی**: صعودی (75% احتمال)
- بازار در حال حاضر در رژیم صعودی است
- 75% احتمال ادامه این وضعیت

#### 📊 **عملکرد استراتژی 1**:
- **در بازار صعودی**: عالی (Sharpe = 1.8, بازدهی = 25%)
- **در بازار نزولی**: ضعیف (Sharpe = 0.3, بازدهی = -5%)
- **در بازار خنثی**: خوب (Sharpe = 1.2, بازدهی = 12%)
- **مقاومت کلی**: متوسط (0.65)

## 🎯 چگونه برای انتخاب استراتژی استفاده کنید؟

### سناریو 1: رژیم مشخص و پایدار
```
اگر رژیم فعلی احتمال > 80%:
→ استراتژی متخصص در آن رژیم انتخاب کنید
مثال: اگر بازار صعودی است، استراتژی با بهترین عملکرد در Bull Market
```

### سناریو 2: رژیم نامشخص یا در حال تغییر
```
اگر هیچ رژیم احتمال > 60% نداشته باشد:
→ استراتژی مقاوم انتخاب کنید (Resistance Score > 0.7)
```

### سناریو 3: انتظار تغییر رژیم
```
اگر نشانه‌های تغییر رژیم وجود دارد:
→ ترکیبی از استراتژی‌های مختلف برای رژیم‌های مختلف
```

## ⚙️ تنظیمات قابل تغییر

### پارامترهای مهم:
- **n_regimes**: تعداد رژیم‌ها (معمولاً 3: صعودی، نزولی، خنثی)
- **min_regime_duration**: حداقل مدت زمان هر رژیم (روز)
- **regime_detection_method**: روش تشخیص ('hmm', 'threshold', 'ml')

### مثال تنظیمات سفارشی:
```python
config = {
    'n_regimes': 4,                    # رژیم اضافی (مثلاً بحرانی)

}
```
