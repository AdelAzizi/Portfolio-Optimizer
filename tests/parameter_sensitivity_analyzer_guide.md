# 🔬 راهنمای تحلیلگر حساسیت پارامترها

## 🎯 هدف و کاربرد

این ابزار برای **تحلیل حساسیت پارامترهای استراتژی‌های سرمایه‌گذاری** طراحی شده است. اگر شما می‌خواهید بدانید که تغییر کدام پارامتر بیشترین تأثیر را بر عملکرد استراتژی‌هایتان دارد، این ابزار دقیقاً همان چیزی است که نیاز دارید.

### 🤔 چرا تحلیل حساسیت مهم است؟
- **شناسایی پارامترهای حیاتی**: کدام تنظیمات بیشترین تأثیر را دارند؟
- **بهینه‌سازی هدفمند**: روی مهم‌ترین پارامترها تمرکز کنید
- **مدیریت ریسک**: از تغییرات ناخواسته جلوگیری کنید
- **اولویت‌بندی نظارت**: بدانید کدام پارامترها نیاز به نظارت بیشتری دارند

## 🔧 چگونه کار می‌کند؟

- **شبیه‌سازی تأثیر**: محاسبه تغییر عملکرد برای هر نقطه

### مرحله 3: محاسبه معیارهای حساسیت

## 📊 معیارهای کلیدی

### 🎯 Sensitivity Score (امتیاز حساسیت)
- **تعریف**: انحراف معیار تغییرات عملکرد
- **محدوده**: 0 تا ∞ (بالاتر = حساس‌تر)
- **آستانه حیاتی**: 0.05 (5%)

### 📈 Max Impact (حداکثر تأثیر)
- **تعریف**: بیشترین تغییر عملکرد در محدوده تست
- **واحد**: درصد تغییر عملکرد
- **مثال**: 0.20 یعنی 20% تغییر عملکرد

### 🏷️ Criticality Level (سطح حیاتی بودن)
- **Very Critical**: امتیاز > 0.2
- **Critical**: امتیاز 0.1 - 0.2
- **Moderately Critical**: امتیاز 0.05 - 0.1
- **Low Impact**: امتیاز < 0.05
